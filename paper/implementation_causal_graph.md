# Implementation: Causal Graph Construction Across Benchmarks

## Implementation Details

### Dataset and Annotation Coverage

We construct the causal error graph from the full annotated trace corpus spanning two agent benchmarks: GAIA~\cite{mialon2023gaia} (117 multi-step question-answering traces) and SWE-bench~\cite{jimenez2024swebench} (31 repository-level software engineering traces), yielding **148 traces** in total. Both datasets share the TRAIL error taxonomy~\cite{TODO} of 19 error categories, enabling joint graph construction. GAIA traces are generated by an o3-mini-based agent; SWE-bench traces by a Claude-3.7-Sonnet-based CodeAgent. The combination of two architecturally distinct agent types increases the breadth of co-occurrence patterns observed, improving the statistical power of the causal discovery.

### Error Onset Extraction

Onset ranks are computed from span timestamps within each trace, using spans of kind LLM, TOOL, or CHAIN (OpenInference span taxonomy). Spans are sorted by timestamp with span\_id as a tie-breaker. For each error category, the onset is the rank of the earliest annotated span. Traces where a category is absent are excluded from the precedence denominator but included in probability-raising calculations as negative examples ($\text{present}=0$).

### Suppes Screening

We apply Suppes screening with the following thresholds, selected to balance edge recall and suppression of low-evidence associations:

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| $\tau_{\text{prec}}$ (min\_precedence) | 0.55 | A precedes B in majority of joint traces |
| $\tau_{\Delta\text{PR}}$ (min\_pr\_delta) | 0.05 | Probability raising of ≥5 percentage points |
| $\tau_{\text{joint}}$ (min\_joint) | 3 | Minimum 3 co-occurring traces to suppress noise |

Applied to the 148-trace corpus across 19 error categories, the Suppes screen retains **27 candidate edges** from the $19 \times 18 = 342$ directed pairs. The strongest edges by probability-raising include: *Tool Selection Errors → Goal Deviation* ($\Delta\text{PR} = 0.47$, $\text{prec} = 1.00$, $n=9$) and *Poor Information Retrieval → Resource Abuse* ($\Delta\text{PR} = 0.42$, $\text{prec} = 0.57$, $n=14$).

A fully-connected Suppes graph (thresholds $\tau_{\text{prec}} = 0$, $\tau_{\Delta\text{PR}} = 0$, $\tau_{\text{joint}} = 1$) is also produced separately and used as the adjacency structure for downstream graph feature encoding (150 edges), preserving weak associations as soft graph weights for graph-based models.

### CAPRI Pruning

We run CAPRI hill-climbing with the AIC criterion on the 27-edge Suppes candidate graph. AIC is preferred over BIC for this setting because the trace corpus is moderately sized (148 traces), and BIC's stronger complexity penalty risks discarding true causal edges with limited observational support. The hill-climbing converges in **14 iterations**, reducing the total score from 2308.3 to 2179.4. The resulting CAPRI graph contains **13 directed edges**:

| Source | Target |
|--------|--------|
| Formatting Errors | Context Handling Failures |
| Formatting Errors | Incorrect Problem Identification |
| Formatting Errors | Poor Information Retrieval |
| Formatting Errors | Resource Abuse |
| Incorrect Problem Identification | Language-only |
| Incorrect Problem Identification | Tool Output Misinterpretation |
| Poor Information Retrieval | Resource Abuse |
| Resource Abuse | Authentication Errors |
| Resource Abuse | Tool-related |
| Tool Selection Errors | Goal Deviation |
| Tool Selection Errors | Language-only |
| Tool Selection Errors | Task Orchestration |
| Tool-related | Goal Deviation |

### Composite Edge Weights

For downstream graph-based applications, each Suppes edge $A \to B$ is assigned a composite weight that jointly encodes precedence strength and probability-raising magnitude, with a shrinkage correction for low-count edges:

$$s_{AB} = \left(\alpha \cdot \text{prec}(A\to B) + (1-\alpha) \cdot \widetilde{\Delta\text{PR}}(A\to B)\right) \cdot \frac{n_{AB}}{n_{AB} + \kappa}$$

where $\widetilde{\Delta\text{PR}}$ is the min-max normalized PR delta across all candidate edges, $\alpha = 0.4$, and $\kappa = 5.0$. Edges validated as causal (see below) are assigned $w = 1.0$ regardless of the composite score, making them distinguishable from correlation-only edges.

### Intervention Validation

To validate the 13 CAPRI edges, we apply the $\text{do}(A{=}0)$ intervention protocol described in §~\ref{sec:methodology}. Eligible traces are those in the training and validation splits containing both the source error $A$ at some span $t_A$ and the target error $B$ at a later span $t_B > t_A$ (strict mode). Test-split traces are excluded to prevent any leakage between the causal graph and downstream evaluation.

**Implementation parameters.** Patch generation and LLM judging (Judge-A, Judge-B) use GPT-4o; counterfactual reruns use the model matching each trace's original agent (o3-mini for GAIA, GPT-4o for SWE-bench), ensuring the counterfactual continuation is drawn from the same generative distribution as the original trace. The rerun length is capped at $K=12$ steps after the patched span, covering the 90th percentile of observed $t_A \to t_B$ step distances. Intervention validity threshold is $\tau_\Delta = 0.15$ with $n_{\min} = 1$, calibrated against a null distribution with mean $-0.52$ and standard deviation $0.20$ estimated via onset permutation (1300 permutation samples).

**Eligible trace filtering.** Before constructing interventions, traces are filtered using three criteria applied in sequence:

1. **Minimum error count**: the trace must have $\geq 2$ total annotated errors. Singleton-error traces cannot exhibit A→B co-occurrence and are excluded.
2. **A-type presence**: the trace must contain at least one error whose category is a source node (A-type) in the CAPRI graph. Source nodes are: *Formatting Errors*, *Incorrect Problem Identification*, *Poor Information Retrieval*, *Resource Abuse*, *Task Orchestration*, *Tool Selection Errors*, *Tool-related*.
3. **Strict mode (B after A)**: in the strict mode used for all GAIA+SWE runs, the trace must also contain at least one (A, B) pair where the B-type error appears *after* the A-type error in annotation order. This ensures every eligible trace contributes at least one baseline-positive edge pair to the effect estimation.

Test-split traces are excluded before filtering to prevent any leakage between the causal graph and downstream evaluation. Applying these three criteria to the GAIA training+validation set yields 72 eligible traces (from 117 total), and to the SWE-bench training+validation set yields 26 eligible traces (from 31 total).

**A-instances and edge pairs.** An *A-instance* is one unique (trace, error occurrence) pair where the error category is an A-type. A single eligible trace can yield multiple A-instances if it contains multiple A-type error annotations — each becomes an independent counterfactual experiment on the same full trace, with a patch applied at that error's span and the rerun continuing from that point to the end of the trace. From the 98 eligible traces, 274 A-instances are constructed in total (192 GAIA + 82 SWE).

Each A-instance defines a single intervention point: the span in the trace where the source error $A$ is annotated. If the annotation points to a TOOL span and the patch template requires editing model output (e.g. fixing a malformed tool call), the intervention is redirected to the sibling LLM span that authored the tool call, because TOOL span inputs are generated by LLM outputs. Both the original annotated location and the actual intervention location are recorded for auditing.

A-instances that share the same intervention location are deduplicated: only the first by annotation index is kept, since applying two overlapping patches to the same span would conflate the causal estimands. This deduplication step removed 37 location-conflict A-instances in GAIA (192 kept out of 229 initial) and 4 in SWE-bench (82 kept out of 86 initial).

Each A-instance fans out to one *EdgePair* per B-type connected to its A-type in the CAPRI graph. An EdgePair records whether the B-type error appears after the A-type error in the original trace (`b_present_baseline`), which forms the denominator of the causal effect estimate $\Delta(A \to B)$. The 274 A-instances expand to 493 edge pairs in total (345 GAIA + 148 SWE).

**Patch generation** uses category-specific repair templates from a shared patch library. Rule-based postchecks enforce: (i) required format markers are present, (ii) patch payload differs from the original span output, and (iii) no ungrounded content is introduced. Patches failing all three retries are discarded.

## Secondary Implementation: MAST Benchmark

To demonstrate that the pipeline generalises beyond single-agent task-completion benchmarks, we apply the same Suppes–CAPRI–intervention pipeline to MAST~\cite{TODO_mast}, a benchmark for **multi-agent conversation** errors. MAST captures coordination failures between agents in dialogue settings, using a structurally distinct error taxonomy focused on inter-agent communication and task handoff.

### Dataset and Taxonomy

MAST provides **393 annotated traces** — 2.7× the size of the GAIA+SWE corpus — across **13 error categories** organised into three tiers:

| Tier | Categories | Semantic Focus |
|------|------------|----------------|
| Task specification (1.x) | 1.1, 1.2, 1.3, 1.4, 1.5 | Individual agent compliance and state management |
| Conversation coordination (2.x) | 2.1, 2.2, 2.3, 2.4, 2.6 | Inter-agent communication and task routing |
| Output quality (3.x) | 3.1, 3.2, 3.3 | Verification and termination correctness |

This taxonomy is structurally distinct from TRAIL's 19-category schema: it emphasises multi-agent coordination errors (e.g., *Conversation Reset*, *Information Withholding*, *Action-Reasoning Mismatch*) that rarely arise in single-agent settings. The pipeline ingests these categories directly from annotation files, with no adaptation to the algorithm.

### Suppes Screening

The same threshold configuration ($\tau_{\text{prec}} = 0.55$, $\tau_{\Delta\text{PR}} = 0.05$, $\tau_{\text{joint}} = 3$) is applied to the 393-trace corpus. The screen retains **43 candidate edges** from $13 \times 12 = 156$ directed pairs — a higher density than GAIA+SWE (43/156 = 27.6\% vs. 27/342 = 7.9\%), reflecting stronger co-occurrence structure in multi-agent conversation errors. The strongest edges by probability-raising are *Conversation Reset → Loss of Conversation History* ($\Delta\text{PR} = 0.87$, $\text{prec} = 0.75$, $n = 16$) and *Loss of Conversation History → Unaware of Termination Conditions* ($\Delta\text{PR} = 0.62$, $\text{prec} = 0.79$, $n = 19$), both reflecting a plausible causal chain in which a context loss event propagates to a termination failure.

Bootstrap stability analysis across 100 resamples identifies 68 candidate edges at least once, with a median stability of 0.51. A shuffle control over 50 random onset permutations yields a mean of $31.2 \pm 4.1$ spurious edges, confirming that the original 43 edges exceed chance levels.

### CAPRI Pruning

For MAST we use the **BIC criterion** rather than AIC. With 393 traces, BIC's stronger $\log n$ complexity penalty ($\log 393 \approx 5.97$ vs. AIC's constant 2) is warranted: the larger corpus provides sufficient evidence to justify stricter structural parsimony. The hill-climbing converges in **15 iterations**, reducing the total score from 5018.7 to 4680.6, pruning 43 Suppes edges to **14 CAPRI-BIC edges**:

|------------|------------|---------------------|
| Disobey Task Specification (1.1) | Task Derailment (2.3) | 0.45 |
| Disobey Task Specification (1.1) | Action-Reasoning Mismatch (2.6) | **0.95** |
| Step Repetition (1.3) | Unaware of Termination Conditions (1.5) | 0.69 |
| Loss of Conv. History (1.4) | Unaware of Termination Conditions (1.5) | 0.76 |
| Conversation Reset (2.1) | Step Repetition (1.3) | 0.60 |
| Conversation Reset (2.1) | Loss of Conv. History (1.4) | 0.66 |
| Conversation Reset (2.1) | No/Incorrect Verification (3.3) | 0.39 |
| Fail to Ask Clarification (2.2) | Loss of Conv. History (1.4) | 0.38 |
| Fail to Ask Clarification (2.2) | Unaware of Termination Conditions (1.5) | 0.65 |
| Fail to Ask Clarification (2.2) | Task Derailment (2.3) | **0.89** |
| Fail to Ask Clarification (2.2) | Information Withholding (2.4) | 0.51 |
| Fail to Ask Clarification (2.2) | Action-Reasoning Mismatch (2.6) | 0.72 |

The topological structure of the pruned graph reveals a three-level causal hierarchy: root causes (*Disobey Task Specification*, *Conversation Reset*, *Fail to Ask Clarification*) at level 0; intermediate propagation errors (*Step Repetition*, *Loss of Conversation History*, *Task Derailment*, *Action-Reasoning Mismatch*, *No/Incorrect Verification*) at level 1; and terminal consequences (*Unaware of Termination Conditions*, *Information Withholding*, *Premature Termination*) at level 2.

### Intervention Validation

The $\text{do}(A{=}0)$ intervention protocol is applied to all 14 CAPRI-BIC edges. Because MAST traces are annotated dialogue transcripts (not live agent executions with tool calls), counterfactual reruns simulate the corrected assistant turns directly via LLM continuation, replaying orchestrator messages from the original trace. A total of 305 A-instances are constructed across six source error categories.

**7 of 14 CAPRI edges** are validated with $\Delta(A \to B) < 0$ and $n \geq 1$:

| Edge | $n$ | $\Delta(A \to B)$ | Validated |
|------|-----|-------------------|-----------|
| Disobey Task Specification → Action-Reasoning Mismatch | 63 | $-0.127$ | Yes |
| Step Repetition → Unaware of Termination Conditions | 86 | $-0.081$ | Yes |
| Loss of Conv. History → Unaware of Termination Conditions | 10 | $-0.100$ | Yes |
| Conversation Reset → No/Incorrect Verification | 1 | $-1.000$ | Yes |
| Fail to Ask Clarification → Unaware of Termination Conditions | 30 | $-0.300$ | Yes |
| Fail to Ask Clarification → Information Withholding | 2 | $-0.500$ | Yes |
| Task Derailment → Premature Termination | 7 | $-0.429$ | Yes |

The placebo null distribution (1700 permutation samples on the AIC-pruned graph) has mean $-0.124$ and standard deviation $0.252$. The 12 unvalidated edges show effect sizes above the practical threshold $\tau_\Delta = 0.15$ — most commonly because the ``not\_observable'' outcome label dominated their B-effect judgments, reflecting cases where the counterfactual continuation did not produce enough context to determine whether $B$ occurred. As with TRAIL, the placebo null is centred negative because the patch+rerun procedure itself attenuates downstream errors regardless of the patched cause; we therefore interpret $\tau_\Delta$ as a minimum-effect-size criterion rather than a null-rejection cutoff (see `paper/appendix.md` §A.1).

### Cross-Benchmark Comparison

The two instantiations demonstrate the pipeline's generality across structurally different benchmarks:

| Property | GAIA + SWE-Bench | MAST |
|----------|-----------------|------|
| Agent type | Single-agent, tool-calling | Multi-agent, conversational |
| Traces | 148 | 393 |
| Error categories | 19 | 13 |
| Suppes edges | 27 | 43 |
| CAPRI criterion | AIC | BIC |
| CAPRI edges | 13 | 14 |
| Validated edges | 10 (of 10 tested) | 7 (of 14) |
| Dominant root causes | Formatting Errors, Tool Selection Errors | Disobey Task Spec., Conversation Reset, Fail to Ask Clarification |
| Dominant consequences | Resource Abuse, Goal Deviation | Unaware of Termination, Premature Termination |

The choice of AIC vs. BIC reflects corpus size: AIC is preferred for the smaller GAIA+SWE corpus (148 traces) to retain more candidate edges, while BIC is appropriate for MAST's larger corpus (393 traces) where the complexity penalty is better calibrated. The structural difference in dominant error chains — low-level formatting cascades in single-agent traces vs. coordination failures propagating to termination errors in multi-agent dialogue — confirms that the pipeline surfaces meaningful benchmark-specific causal patterns rather than generic artifacts.

See `paper/appendix.md` §A.1 for a clarifying note on how to interpret the intervention-validity threshold $\tau_\Delta$.
