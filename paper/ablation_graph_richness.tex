% ABLATION — Graph Richness (causal-only vs. corr >= 0.2)
%
% Methodology paragraph (for inclusion in the paper body):
% --------------------------------------------------------
%
% \paragraph{Graph-richness ablation.}
% To isolate the contribution of edge-set richness from that of the
% injection architecture, we ablate the size of the causal graph
% supplied at inference time while holding every other component fixed.
% Beyond the \textsc{causal-only} graph (the 12 intervention-validated
% edges used in the main results), we sweep three correlation
% thresholds $\tau\in\{0.35,\,0.25,\,0.20\}$ that admit increasingly
% rich subsets of the Suppes candidate pool, and a null-graph
% \textsc{random-12} control that samples 12 directed edges uniformly
% from the full taxonomy excluding all Suppes-screened pairs (seed
% fixed at 42).
% Each candidate edge $A\!\to\!B$ in the Suppes pool receives a
% \emph{geometric-mean score}
% $\mathrm{score}(A\!\to\!B)=\sqrt{P(A\text{ precedes }B\mid \text{both})\;\cdot\;\Delta_{\mathrm{PR}}(A\!\to\!B)}$,
% where the first factor is the empirical temporal-precedence rate and
% $\Delta_{\mathrm{PR}}(A\!\to\!B)=P(B\mid A)-P(B\mid \neg A)$ is the
% Suppes probability-raising signal. These are the two graded Suppes
% statistics used to admit edges in the screening stage, and they are
% independent (precedence is computed only on traces where both $A$
% and $B$ occur, while $\Delta_{\mathrm{PR}}$ contrasts $B$'s rate
% under presence vs.\ absence of $A$). Both factors lie in $[0,1]$,
% so the geometric mean is monotone in each and penalises edges that
% are strong on only one criterion; in particular, edges with high
% precedence but negligible probability-raising — co-occurrences in
% which $B$ would have occurred anyway — receive a low score, and
% conversely for high $\Delta_{\mathrm{PR}}$ but low precedence.
% Suppes admission already requires
% $\Delta_{\mathrm{PR}}{\geq}0.05$ and $\mathrm{precedence}{\geq}0.55$
% as conjunctive floors during graph construction, so the geomean
% score is not comparable to either floor: it sits on a combined
% $[0,1]$ scale and provides a ranking among already-admitted
% candidates. At each $\tau$ the corr~$\geq\tau$ edge set is the
% union of (i) all Suppes edges with geomean $\geq\tau$ and (ii) the
% 12 intervention-validated causal edges (kept regardless of geomean
% so that no main-result edge is dropped by the threshold filter).
% The three points yield edge-set sizes $\{19,21,25\}$, anchored
% against \textsc{causal-only} ($12$) and \textsc{random-12} ($12$,
% null-graph control).
% We hold the threshold and edge set fixed across models and splits and
% evaluate two complementary injection strategies under each: a one-pass
% static-graph variant (+CG), where the entire edge set is appended to
% the prompt before the yes/no question, and the two-pass dynamic
% injection variant (+GI+SI), where Pass~1 detects errors with no graph
% and Pass~2 injects only the targeted subgraph rooted at the detected
% errors, augmented with a span index. The ablation is scoped to the
% open-source panel; closed-source Gemini models are excluded so that
% the contrast cannot be confounded by API-side behaviour.
%
% --------------------------------------------------------
%
% Purpose: show how expanding the injected graph from 12 causal
% edges to 18 observationally-screened edges (geomean >= 0.2)
% affects +GI+SI performance across the open-source model panel.
% Also includes the one-pass +CG variant at the same threshold
% (corr t0.2, same 18-edge set) to demonstrate that the two-pass GI
% architecture is what allows the larger graph to help.
%
% Sources:
%   causal-only +GI+SI : outputs/zero_shot2/*-graph_inject_causal_only_span_index-metrics.txt
%   corr0.2    +GI+SI  : outputs_thres/t0.20/*-graph_inject_causal_corr0.2_span_index-metrics.txt
%                        (QwenLong: outputs_thres/t0.20/*-graph_inject_suppes_t0.2_span_index-metrics.txt)
%   corr_t0.2  +CG     : outputs_thres/t0.20/*-graph_t0.2-metrics.txt

%
% Edge sets (from suppes_graph.json):

% Take-aways (for paper text reference, not part of the table):
%
% 1. Expanding the injected graph from 12 to 18 edges (causal-only ->
%    corr>=0.2) under +GI+SI yields large W-F1 gains on 3 of 4 open-source
%    models with completed runs:
%      - Mistral GAIA  : 30.76 -> 36.93 (+6.17)
%      - GPT-120B GAIA : 30.14 -> 36.44 (+6.30)
%      - GPT-20B  GAIA : 22.29 -> 32.04 (+9.75)
%      - GPT-120B SWE  : 27.13 -> 35.32 (+8.19)
%      - GPT-20B  SWE  : 13.03 -> 18.68 (+5.65)
%    Gemma is the exception: corr>=0.2 hurts on both splits
%    (-4.31 GAIA, -2.41 SWE), suggesting hint-overload sensitivity
%    in mid-size instruction-tuned models.
%
% 2. Loc and Joint are largely unchanged on GAIA across the two
%    +GI+SI variants. The W-F1 lift comes from broader category
%    coverage (esp. Environment Setup), not from better localization.
%    On SWE, Loc improves uniformly (+1-3 pts) off near-zero baselines.
%
% 3. The one-pass +CG variant at t>=0.2 (corr, same 18-edge set) is uniformly worse
%    than +GI+SI causal-only across all three GAIA models tested:
%      - Gemma   : 22.53 vs 25.30 (-2.77)
%      - GPT-120B: 26.72 vs 30.14 (-3.42)
%      - GPT-20B : 21.74 vs 22.29 (-0.55)
%    The two-pass GI architecture is what allows the larger graph
%    to help; a static, undifferentiated edge list does not scale.
%
% 4. Context-budget impact of corr>=0.2 in +GI+SI is negligible:
%    Pass 1 carries no graph; Pass 2 injects only the targeted
%    subgraph (1-3 edges). N coverage actually increases for Mistral
%    (64->74) and GPT-20B (87->90) on GAIA. QwenLong corr0.2 GAIA is
%    partial (84/117); the W-F1 lift over causal-only (16.83 -> 23.35)
%    is consistent with the other open-source models even with the
%    33 missing traces scored as empty.
%
% 5. Implication for main table: corr>=0.2 is the dominantly better
%    +GI+SI setting on open-source models (Gemma excepted). The main
%    table swap is out of scope for this ablation (closed-source
%    Gemini rows are not part of the ablation study), but the
%    finding stands as evidence that the two-pass GI architecture
%    benefits from observationally-screened edges beyond the strict
%    causal-only set.
