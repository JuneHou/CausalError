% Take-aways (for paper text reference, not part of the table):
%
% 1. Expanding the injected graph from 12 to 18 edges (causal-only ->
%    corr>=0.2) under +GI+SI yields large W-F1 gains on 3 of 4 open-source
%    models with completed runs:
%      - Mistral GAIA  : 30.76 -> 36.93 (+6.17)
%      - GPT-120B GAIA : 30.14 -> 36.44 (+6.30)
%      - GPT-20B  GAIA : 22.29 -> 32.04 (+9.75)
%      - GPT-120B SWE  : 27.13 -> 35.32 (+8.19)
%      - GPT-20B  SWE  : 13.03 -> 18.68 (+5.65)
%    Gemma is the exception: corr>=0.2 hurts on both splits
%    (-4.31 GAIA, -2.41 SWE), suggesting hint-overload sensitivity
%    in mid-size instruction-tuned models.
%
% 2. Loc and Joint are largely unchanged on GAIA across the two
%    +GI+SI variants. The W-F1 lift comes from broader category
%    coverage (esp. Environment Setup), not from better localization.
%    On SWE, Loc improves uniformly (+1-3 pts) off near-zero baselines.
%
% 3. The one-pass +CG variant at t>=0.2 (suppes) is uniformly worse
%    than +GI+SI causal-only across all three GAIA models tested:
%      - Gemma   : 22.53 vs 25.30 (-2.77)
%      - GPT-120B: 26.72 vs 30.14 (-3.42)
%      - GPT-20B : 21.74 vs 22.29 (-0.55)
%    The two-pass GI architecture is what allows the larger graph
%    to help; a static, undifferentiated edge list does not scale.
%
% 4. Context-budget impact of corr>=0.2 in +GI+SI is negligible:
%    Pass 1 carries no graph; Pass 2 injects only the targeted
%    subgraph (1-3 edges). N coverage actually increases for Mistral
%    (64->74) and GPT-20B (87->90) on GAIA. QwenLong is the exception
%    (corr0.2 dir empty) and needs re-runs to verify whether the
%    failure is context-related or a launch issue.
%
% 5. Implication for main table: corr>=0.2 is the dominantly better
%    +GI+SI setting on open-source models (Gemma excepted). The main
%    table swap is out of scope for this ablation (closed-source
%    Gemini rows are not part of the ablation study), but the
%    finding stands as evidence that the two-pass GI architecture
%    benefits from observationally-screened edges beyond the strict
%    causal-only set.
